Privacy Policy — Hermes Backup

Last updated: 16 October 2026

Hermes Backup is a private, single-user automation. Its only user is the owner of the Google Account it runs under. It is not distributed or offered as a service to anyone else.

What data it accesses

The application requests one Google API permission: https://www.googleapis.com/auth/drive.file. This scope allows it to create and manage only the files and folders it created itself. It cannot read, list, modify or delete any other file in the user's Google Drive.

What data it stores

It uploads a compressed archive of the owner's own configuration files to a folder it created in that same Google Drive account. The archive contains no information about anyone other than the owner, and it deliberately excludes all credentials, passwords and API keys.

What it does not do

  • No personal data is collected from any third party.
  • No data is transmitted to, sold to, or shared with any third party.
  • No data leaves the owner's own Google Drive account.
  • No analytics, tracking, cookies or advertising.
  • No use of Google user data to train machine-learning models.

Data retention and deletion

Archives are retained on a rolling schedule (7 daily, 4 weekly, 12 monthly, and yearly copies) and older copies are deleted automatically. The owner can delete every stored archive at any time by removing the Hermes Backups folder in Google Drive, and can revoke the application's access at any time from myaccount.google.com/permissions.

Limited Use disclosure

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

This application is operated privately by its owner. Questions about this policy can be raised through the owner's own account.
