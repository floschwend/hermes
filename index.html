Hermes Backup

Hermes Backup is a private automation that keeps versioned snapshots of its owner's own configuration files. It runs unattended once a day on the owner's machine and uploads a single archive to a folder inside the owner's own Google Drive account.

What it does

  • Creates one compressed archive of the owner's configuration, skills and notes.
  • Uploads that archive to a folder it created in the owner's Google Drive.
  • Keeps a rolling history (7 daily, 4 weekly, 12 monthly, and yearly copies).

What it does not do

  • No accounts, no sign-up, no third-party users. It is used by exactly one person: its owner.
  • No analytics, no tracking, no advertising.
  • No access to any Drive file it did not create itself.

The application requests a single Google permission, drive.file, which restricts it to files and folders it created itself. It has no ability to read or modify the rest of the Drive.
